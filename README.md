# Realistic Resume Project

## Description
This is a responsive and interactive resume webpage with a flip card design. It showcases my professional experience, skills, education, and projects.

## Features
- Flip card design (front and back)
- Responsive layout
- Social media links
- Project links

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Clone the repository.
2. Open `index.html` in your browser.
